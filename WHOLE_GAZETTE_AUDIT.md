# Reference audit - Gazette v3

Thirteen supplied department PDFs contain 2,762 pages. All were scanned for text/drawing geometry. The catalog holds 120 measured academic header/grid profiles covering 2,734 academic/fee-compatible pages, two additional fee-only pages, and 26 front-matter pages. No page remains unclassified. Source page references and hashes are retained.

All 120 header profiles render. A synthetic complete gazette was generated for every department family: Computer Science, Management Sciences, Allied Health/Biology, Art/Humanities, Chemistry, Criminology, English, Information Technology, Mathematics, Media/Communication, Physics, Psychology and Software Engineering. Each has zero extracted words outside page bounds. Cover and body contact sheets were visually inspected. A common reference artwork is used for editable covers because original raster title bands occupy different positions; text-region geometry is external catalog data. Original department body structures remain selected from the measured catalog.

Criminology uses Adj. GPA rather than CGPA in its final ratio column. That heading is preserved; cumulative CGPA is supplied in a companion summary. Other current gazettes select CGPA-capable reference variants when available, retaining actual source cohort/term labels. Fee tables use the measured identity-column boundaries and appear at the end, with content-driven row heights and pagination.

Reference PDFs are formatting evidence only. No source-reference student names, results or fee statuses populate application datasets or examples. The original files are unchanged.
